# Content Inbox — Drop Files Here

This folder is for dropping raw photos, documents, and artifacts for review and inclusion in the site.

## Folders

| Folder | What to put here |
|---|---|
| `photos/` | Any photos — interior, exterior, detail shots, historical photos |
| `floor-plans/` | Original architectural drawings, blueprints, plans |
| `documents/` | Write-ups, historical records, newspaper clippings, letters, deeds |
| `artifacts/` | Scans of any physical artifacts — postcards, permits, correspondence |

## After dropping files in

Tell Claude Code what you've added and ask it to:
- **Analyze photos** to help write captions and identify the best shots for each section
- **Read documents** to extract content for the History and Original Owners sections
- **Process floor plans** to prepare them for the site

## Where files end up on the site

Once reviewed and processed, files are copied to:
- `public/images/hero/` — hero background photo (needs to be a great exterior shot)
- `public/images/gallery/` — photo gallery images
- `public/images/floor-plans/` — architectural drawings
- `public/images/owners/` — portrait or photo of original owners
